# Ручная приёмка UI v1

## BUG-UI-001 — частично успешный поиск помечается как полностью неуспешный

- Статус: `open`
- Обнаружено: 2026-08-20, ручная приёмка `feature/ui-v1-html-mockup`
- Затронутая операция: `manual_search`

### Шаги

1. Открыть Postify UI.
2. Запустить новый поиск.
3. Дождаться завершения анализа и генерации пакетов.

### Фактический результат

Если хотя бы один материал или медиа-шаг завершается ошибкой, вся
ручная операция помечается как `failed` с кодом
`manual_search_failed`, даже если часть пакетов успешно создана и готова к проверке.
UI показывает общую ошибку команды.

В зафиксированном запуске:

- 12 материалов взято в работу;
- 8 проанализированы, но не отобраны;
- 1 материал завершился с `article_unavailable`;
- 2 пакета созданы со статусом `awaiting_review`;
- 1 пакет завершился с `media_failed`;
- итог операции: `failed`, `packages_created=2`.

### Ожидаемый результат

Частичные сбои отдельных материалов или медиа не должны скрывать
успешно созданные пакеты и превращать весь запуск в бинарный неуспех.
UI должен показать созданные пакеты и отдельно сообщить о частичных ошибках.

### Техническое наблюдение

Backend поднимает `manual_content_failed`, когда `content_result.failed > 0`,
не учитывая `content_result.packages_created > 0`. Frontend воспринимает этот
запуск как полную ошибку.

Исправление не выполнялось.

## FEATURE-UI-001 — собственный формат и тестовая генерация поста

- Статус: `open`
- Тип: feature request
- Раздел: «Настройки → Генерация и форматы»

### Проблема

Текущий формат постов в UI только отображается: пользователь не может
задать свои инструкции для генерации и быстро проверить, в нужном ли направлении
модель пишет посты.

### Желаемое поведение

1. В разделе «Генерация и форматы» есть input/текстовое поле для собственных
   инструкций формата поста.
2. Пользователь вводит или правит свой prompt и нажимает «Сгенерировать тестовый
   пост».
3. Luna генерирует один тестовый пост по этому формату; результат показывается в UI.
4. Пользователь оценивает направление текста, правит prompt в том же поле и может
   снова запустить тестовую генерацию.

### Границы

- Тестовая генерация не создаёт content package, задачу публикации, медиа или доставку.
- Результат нужен исключительно для итеративной настройки формата.
- Инструкции должны явно уточнять, что результат — пост для соцсети, а не
  локальная инструкция или объяснение для одного читателя.

Исполнение не выполнялось.
