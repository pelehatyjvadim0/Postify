## Граница

Базовое состояние: `main@e8370b9`. Пакет содержит только тесты отбора и это доказательство; рабочего кода Wave 2 нет. Целевой переход — объяснимое неизменяемое решение `selected`/`rejected` для каждого кандидата после `run-once`.

## Аудит RED: окружение или поведение

| Проверка | Результат | Вывод |
| --- | --- | --- |
| Retained non-integration до изменений | 72 GREEN | зависимости и обычные фикстуры исправны |
| Retained integration до изменений | 14 GREEN | PostgreSQL доступен по выделенному URL, Alembic и psycopg исправны |
| Collection новых non-integration | все новые узлы собраны | импорты новых модулей находятся внутри test body; collection не блокируется |
| Новая конфигурация | RED: DID NOT RAISE либо отсутствует attribute | нет требуемого поведения, не ошибка Pydantic/fixture |
| Domain/application/jobs | RED на `ModuleNotFoundError: postify....<новый модуль>` внутри конкретного узла | отсутствует production-контракт Wave 2; сторонняя зависимость не отсутствует |
| CLI | RED на отсутствии `open_run_once` или на утечке ValidationError | отсутствует wiring/error hygiene; Typer runner исправен, start/status/stop GREEN |
| Migration | retained migration nodes GREEN; новые RED на отсутствии таблицы/head | БД и Alembic исправны; отсутствует новая migration |
| Repository | каждый узел стартует после успешного `migrated_database_url`, затем RED на отсутствующем decision domain/repository | не fixture/connection failure; concurrency и rollback будут достигнуты после появления контракта |

Таким образом исходный RED поведенческий. Импортные RED допустимы на этой стадии: они происходят после успешной collection внутри каждого точного node ID и обозначают отсутствующие файлы, прямо перечисленные в плане.

## Отклонение карты файлов
