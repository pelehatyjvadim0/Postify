1. Full baseline вернул `16 failed, 688 passed`: session Playwright
   оставлял running loop для поздних `asyncio.run`. Класс потери:
   **интеграция**. Исправлен lifetime fixture.
2. Wheel e2e последовательно нашёл `404` для `/static/styles.css`
   и `404` для bootstrap. Класс: **интеграция**. Добавлен mount и
   существующий idempotent bootstrap action в composition root.
3. Seeded acceptance нашла materials/packages `503`. Класс:
   **тестовый дизайн**: пустая component fixture не доходила до
   `mappingproxy` и nullable filter. Добавлены два RED component tests.
4. Первый visual capture имел Playwright `CancelledError`, а reused-page
   contact sheet — промежуточные route states. Класс: **инструментарий**.
   Request завершается до close, каждый screen снимается в новой Page;
   финальный capture чист.
5. Full Ruff нашёл `11` F401. Класс: **интеграция**. Удалены
   два unused import; dynamic `locals()` test namespace заменён явным без
   изменения test behavior.
6. Important review нашёл caller-environment leak в wheel e2e. Класс:
   **тестовый дизайн**. Hostile ambient Fernet/Telegram/HN/timezone
   создал channel/route (`1 failed in 3.26s`). Build/install/runtime env
   заменён OS allowlist и явными тестовыми values; GREEN `1 passed in 3.32s`.

Bottleneck: доказать одновременно hermetic wheel и populated UI на
реальной PostgreSQL-границе.

## Решение

push/merge не выполнялись, worktree не удалялся. Временные
PostgreSQL schemas и одноразовый PostgreSQL 16 container удалены после
финального gate Task 11.
