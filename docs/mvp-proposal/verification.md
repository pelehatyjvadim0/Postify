Единственная ошибка первого запуска: конструктор ProcessContent обращался к
метаданным анализатора даже при пустой очереди. Чтение перенесено к фактической

Финальный запуск включает этот regression, MVP pipeline и браузерные сценарии.

Mutation выполнена в удаляемом контейнерном слое: удалён только SQL-предикат
`AND p.scheduled_at <= :now`. Проверен именно assertion ранней отправки, а не
ошибка setup/SQL. Образ и рабочее дерево остались без мутации.

## Независимый смысловой review

Оркестратор проверил тесты источника/Gemini: подмена только внешних границ,
assertions на оригинал, запрос, структурированный результат и ошибки. Проверил
реальные PostgreSQL-тесты дедупликации, плана, модерации, адресной доставки,
конкурентных решений, очереди, рестарта и uncertain. UI-тесты проверяют payload UTC,
перезагрузку, запрет approve без сохранённого плана и отображение ошибок.
Исполнитель источника независимо прочитал MVP pipeline оркестратора; слабая
проверка очистки настройки была усилена чтением значения до и после очистки.

По уточнению пользователя default опоздание не ограничено: при старте уходят
накопившиеся принятые посты. Тест после недельного простоя проверяет фактические
вызовы publisher и сохранённые published, исключение awaiting/rejected,
восстановление uncertain и отсутствие повторной отправки при следующем запуске.
Внешний Telegram при этом заменён тестовым publisher; это не реальная публикация.

Отдельный проект «Демо — тестовые данные» (id 2) содержит одно предложение,
созданное через реальный импорт/pipeline с нейтральным источником и mock Gemini.
Источник отключён, каналов/маршрутов нет. Данные доступны через API проекта 2;
текущий UI по существующему поведению открывает первый проект AutoPostTG.
Скрипт и результат: `seed-demo.py`, `seed-demo.log`. Это синтетические данные,
не свидетельство качества перевода модели.

## Оставшаяся внешняя приёмка

1. VPS: SSH-доступ и способ доступа редактора (туннель/закрытая сеть или домен).
2. Telegram-группа: способ чтения, новые сообщения или история; реальный reader
   ещё не подключён, отсутствие доступа возвращает явную ошибку.
3. Gemini: ключ, доступность модели в проекте, реальная генерация и оценка редактора.
4. Telegram-канал: реальная отправка принятого поста и подтверждение message_id.
5. Новый URL Git до коммитов/push/изменения remote.

Коммитов, push и изменений remote не было. Исходные пользовательские удаления
`docs/development-loop` сохранены. Полный несвязанный legacy-набор не запускался.
